# Martin Piceno

I build AI workflows, mathematics software, and Linux tools. I’m the founder of [ProofAnvil](https://proofanvil.com) and a Mathematics–Computer Science student at UC San Diego.

My focus is turning a useful idea into a working system: define the requirements, direct agents through implementation, test the boundaries, and make the result understandable to the people using it.

A native Japanese-study client I’m building for personal use: lessons, reviews, listening practice, offline study and selection lookup. I direct the study workflow and agent-assisted implementation, with particular attention to preserving saved answers and handling uncertain API submissions.

## How I work

AI agents do substantial implementation work in my projects. My responsibility is to define the problem and acceptance criteria, direct the work, evaluate the evidence, and own the decisions about what ships. I distinguish a passing synthetic test from a result verified in a running product.

My projects use TypeScript, React, Python, SQL, Cloudflare Workers/D1, automated tests, and Linux tooling. I’m interested in AI implementation, workflow automation, AI enablement, and solutions consulting in San Diego or remotely in the US.

## Background and contact

My earlier work spans Marine Corps avionics, electrical test and turbine work, data management and QA at Safran, and electromechanical test and calibration at MagCanica. That experience informs my attention to failure handling, clear procedures, and verifiable results.
