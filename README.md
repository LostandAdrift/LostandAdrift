# Martin Piceno

I’m a Mathematics–Computer Science student at UC San Diego and the founder of [ProofAnvil](https://proofanvil.com), building reliable software, AI-assisted systems, and Linux tooling.

## What I’m building

- **[ProofAnvil](https://proofanvil.com)** — a web platform for deliberate mathematics practice, built with TypeScript, React/Next.js, Cloudflare Workers/D1, Drizzle ORM, and OpenAI APIs. The application source is private; the public engineering overview lives in the [ProofAnvil case study](https://github.com/LostandAdrift/proofanvil-case-study).
- **[gentoo-ironroot](https://github.com/LostandAdrift/gentoo-ironroot)** — a safety-first Gentoo workstation installer with hardware identity locks, LUKS2/Btrfs, deterministic planning, recovery-aware automation, and tests.
- **Hermes Linux skills** — practical agent procedures for [Steam/Proton diagnostics](https://github.com/LostandAdrift/hermes-skill-steam) and [Hyprland 0.55+ Lua configuration](https://github.com/LostandAdrift/hermes-skill-hyprland).

## How I work

I care about correctness, traceability, recovery, and the difference between code that was written and a result that was actually tested and working. My current work spans TypeScript, React/Next.js, Python, SQL, Cloudflare Workers/D1, GitHub Actions, CI/CD, Linux, authentication, software testing, and AI-assisted engineering workflows.

That safety-critical background still shapes how I design and verify systems.

I’m completing a B.S. in Mathematics–Computer Science at UC San Diego, expected June 2027, and I’m open to software engineering, product engineering, developer-tools, and platform roles in San Diego or remote/hybrid environments.
